## 🔹 Positioning Recommendation

Lead with a single sentence, everywhere: **"Backend engineer working in Go and Python on Kubernetes-based distributed systems, with full-stack ownership in TypeScript and React and production experience evaluating generative-AI systems."**

**Emphasise, in this order:**
1. **Kubernetes controllers for a globally distributed API gateway at 100k+ requests/day** — this is the strongest single line in the profile and it maps onto #1, #2, #9, #10, #13 and #14 directly. It is also the line that separates the candidate from the large pool of "full-stack developers."
2. **Go and Python as first-class backend languages**, not as secondary skills.
3. **100k+ documents/day in production at Qualtrics** — evidence of throughput and of systems that had to keep working.
4. **Generative-AI evaluation and improvement**, plus text analytics, classification and summarisation — the genuine differentiator for #8, #12 and #14, and increasingly for ordinary backend reqs.
5. **MSc in Computer Science, University of Maryland** — load-bearing, not decorative, at #2 and #11 where it halves the experience requirement, and at #15 where a CS degree is a hard gate.
6. **Root-cause analysis and production debugging** — name specific incidents and what the analysis changed.

**De-emphasise:**
- **Freelance teaching and vocational-instructor work.** It is real evidence of communication and mentoring and belongs in one line near the bottom — but it must never be positioned as, or allowed to be read as, professional software-engineering tenure. Conflating the two is the fastest way to lose credibility in a screen.
- **Teaching-assistant roles** beyond a single line under education.
- **Frontend framework breadth and CSS depth.** The candidate is not competing for frontend roles; React and TypeScript should appear as *full-stack ownership over a backend*, never as the headline.
- **Academic ML and data-science research.** Useful colour for #8, #12 and #14; actively counterproductive elsewhere, where it invites a "wants to be a data scientist" misread.
- **Breadth-for-its-own-sake technology lists.** Six technologies with production evidence behind each beat twenty with none.
