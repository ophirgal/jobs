## 🔹 Positioning Recommendation

Position as a **Backend / Platform Software Engineer specializing in Go and Python on Kubernetes, with production experience in scalable cloud services and AI-enabled products** — not as a generic full-stack developer.

**Lead with, in this order:**
1. **Kubernetes-controller development for a globally distributed API gateway handling 100,000+ requests/day** — this is the differentiating asset. It reads as platform/infrastructure engineering with real production scale, and it is what unlocks reqs #1, #2, #9, #10 and #15.
2. **Go and Python as co-primary backend languages**, with REST/RPC APIs, distributed services, PostgreSQL/SQL, Docker, AWS and Linux as the supporting production stack.
3. **Generative-AI systems built and evaluated in production**, plus pipelines processing **100,000+ documents/day** — the scarce credential. It is decisive at Workday/Paradox (#13), and materially helps at ScyllaDB (#7), Fluidstack (#9), Garner (#5) and Google Notification Platform (#4), whose minimum *requires* LLM-integration experience.
4. **Root-cause analysis and production debugging** — name specific defects found and fixed. Four reqs here (#8, #11, #12, #14) name debugging or reliability ownership as a core requirement rather than a nice-to-have.
5. **MSc in Computer Science, University of Maryland (3.9 GPA)** — state it early on the three Google reqs specifically, because it is not a credential there but a *satisfied minimum qualification*.

**De-emphasize:**
- **Freelance and vocational teaching tenure as engineering experience.** Present teaching once, as evidence of communication, mentoring and technical explanation — never folded into the years-of-experience count. The retrieved resume currently leads its work history with two instructor entries; for these applications the software-engineering roles should appear first, or screeners will read the profile as an instructor pivoting into engineering rather than as a working backend engineer.
- **Frontend-centric framing.** React/TypeScript is range, not the headline — leading with it misreads the target role families and invites frontend reqs.
- **Academic ML and data-science research as a research identity.** Frame it as applied engineering judgment on AI systems; a research-scientist read actively hurts on hands-on backend reqs.
- **Breadth-for-its-own-sake lists.** A long undifferentiated technology list dilutes the Go + Kubernetes + scale story that is doing the actual work here.
